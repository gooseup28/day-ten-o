군 복무 중에 만든 일정·휴가 관리 웹앱이에요. 입대일만 넣으면 전역까지 남은 날을 계산하고, 휴가와 근무 일정을 한 화면에서 관리해요.

  • 전역 카운트다운
    전역일, 실시간 복무율, 주말·공휴일을 뺀 남은 일과일 자동 계산
  • 휴가 관리
    연가·포상·위로 휴가를 받은 내역별로 관리, 일정에 쓰면 자동 차감
  • 휴가·근무 캘린더
    외출·외박·휴가와 당직·CCTV·위병소 근무를 따로 관리
  • 공휴일 자동 표시
    설·추석 연휴와 대체공휴일까지 규칙대로 계산
이렇게 써보세요
  1. 날짜를 누르면 일정·할 일·메모가 보여요. 카드를 좌우로 밀면 수정·삭제
  2. 아래 + 버튼 → 연가를 골라 저장하면 남은 휴가가 줄어요
  3. 왼쪽 위 메뉴는 휴가 현황, 오른쪽 위 프로필은 복무율과 근무 캘린더 전환
  4. 설정에서 다크 모드·테마 색·글자 크기 바꾸기
